# 《地貌猜地点》野外考察手账

网页版"猜地点"小游戏：**老队长**（出题人）心里藏了一处全球典型地貌，一格一格递线索；你猜地名，他判对错、记分、写红批注；翻底后给**完整地理推理链**。零依赖、离线可玩、file:// 直开亦可。

双主题全部取色自"参考图"里的真实摄影（大理洱海 × 张掖丹霞）：暗色「**洱海暮航**」夜蓝打底日落金做灯；亮色「**水岸处方**」蒲苇白纸面 + 墨青字 + 钴蓝主强调。设置页有**老队长的胶片盒**——点缩略图换 hero 背景；Q11 揭晓时亮出实景照。手账质感（纸噪点、折痕、胶带便签、手绘线条、红笔批注、页码）两主题各自成立。

```
启动.bat          ← 双击启动（端口 8942，自动开浏览器）
node server.js    ← 或手动起服务
```

## 玩法

- 每题 5 条线索，由模糊到具体（气候 → 岩性 → 外力 → 形态 → 标识），第一条免费，之后每条 -15 分
- 2~3 条付费提示（-12 分/条），猜错一次 -7 分；得分下限 15，认输 0 分
- 裁判判定链：**全对**（答案/别名/市级）→ **典型误猜**（点破你与哪个名山混淆了）→ **类型命中**（地貌类型对，位置不对）→ **大区命中** → **未中**（给思维方向提示）
- 揭晓后：答案卡（位置/坐标/别名）+ **"已鉴定"印章** + **全球落点地图**（真实海岸线 + 坐标标注 + 落点脉冲）+ **分步地理推理链** + 冷知识 + 猜测回顾
- **双主题**：暗色夜景 / 亮色手账（牛皮纸+印章风，含打印适配），页头 📜 按钮切换，偏好本地记住
- **音效**：WebAudio 纯合成（答对琶音 / 一击命中闪音 / 猜错闷响 / 结算号角），🔊 按钮开关，偏好本地记住
- **连击与徽章**：连对计数（≥2 火焰高亮 + toast），结算页 6 枚徽章（首战告捷/一击命中/满分大师/三连击/十题百炼/环球旅行家）
- 支持按 11 类地貌筛选、按难度筛选；随机种子可复现整局出题顺序（同种子 = 同题目序列）
- **自动存档**：每一步实时存进浏览器（关页面/隔天回来点"继续上次"无缝续玩）；结算后计入**生涯战绩**（跨会话累计积分/答对/最长连对）；换设备用"导出存档 / 导入存档"搬运（存档码是一段 JSON 文本）

## 架构（可测试性优先）

```

                         （水岸/日落/丹霞三景，hero 背景与"手绘明信片"都用它）
tools/fetch-wiki.js      按题联网找图：Wikimedia Commons 自由版权（CC/PD），

js/sfx.js                WebAudio 纯合成音效（无素材无外链，localStorage 开关）
js/ui.js                 浏览器薄壳（只渲染与绑定：双主题/绘画胶片盒/实景照/地图落点/连击/徽章）
test/test.js             自动化测试 + 生成 report/质检报告.md
```

## 防泄露设计（AI 出题人 × 自动质检）

每套题带 **black 黑名单**（易泄露专名）+ 答案/别名/市级自动并入泄露词表，测试逐条扫描**线索、提示、误猜引导、裁判话术**：

- 揭晓前任何文本不得出现泄露词（大小写/标点归一化后匹配）
- 线索渐进性：前 3 条禁止出现国家/区域词；**末条线索必须含国家或区域锚点词**（保证可解）
- 唯一白名单机制：称号类词可声明 `late:[...]`，仅放行到末条线索（如 Q23"天下黄土第一塬"）
- 运行时模糊测试 200 局，逐句扫描裁判话术防运行时泄露
- 软剧透检查：揭晓前文本提到**别题答案**会产出警告供人工复核

首轮测试抓出 80 处问题（提示复述答案词、子串泄露、裁判 token 未归一化等），修复迭代至全绿，历程记录在质检报告。

## 视觉系统

- **配色取自真实摄影**（参考图/，大理洱海 × 张掖丹霞）：暗色「洱海暮航」、亮色「水岸处方」全部从这些照片里取色，11 类地貌主题色亦按照片色相同源微调
- **程序绘画而非嵌图**：用户提供的照片不直接打包分发，`js/paint.js` 按其配色与构图生成原创 SVG 风景画（水岸/日落/丹霞三景）——设置页胶片盒可换画；Q11 揭晓附"老队长手绘·意象画"明信片
- **按题实景照**：`tools/fetch-wiki.js` 为每题从 Wikimedia Commons 抓一张自由版权（CC/PD）照片，署名（作者·许可·来源）在 `js/wiki-photos.js` 随揭晓页展示；检索词人工选定，支持定向重抓；无网/无图时自动隐藏
- 世界地图为构建期产物（`tools/build-map.js` 解码 TopoJSON → 单条 SVG path），运行时零依赖零请求
- 手账质感（亮色）：纸噪点、折痕水渍、蓝白胶带便签、卡片微歪、楷体红批注、页码页脚；手绘 logo/头像用 feTurbulence+feDisplacementMap 手抖线条

## 扩展新题

1. 在 `data/source/part*.js` 按现有字段加题（id 递增，注意 black 黑名单写全易泄露专名）
2. `node tools/build.js && node test/test.js`
3. 测试会替你抓泄露答案、缺锚点、裁判误判——按报告修复直至全绿
