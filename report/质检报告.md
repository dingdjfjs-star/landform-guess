| 轮次 | 失败项 | 主要问题与修复 |
|---|---|---|
| 1 | 80 | ①提示/误猜引导直接复述答案词 9 处（如提示说出"彩色丘陵"、误猜引导复述"米埔""罗布泊""盖朗厄尔"）→ 全部改写为描述性说法；②"石拱门"含别名"拱门"等子串泄露 → 改写线索；③裁判判定的 token 未归一化，带连字符答案（恒河-布拉马普特拉三角洲）与带空格外文别名判不出全对 → 修引擎 contains |
| 2 | 3 | ①测试脚本快照顺序错误；②模糊测试未对末条线索的 late 白名单词放行；③2 字词（山口/拱门）被"火山口/海蚀拱门"误中产生软剧透误报 → 修测试 |
| 3 | 0 | 全绿（24275 项断言） |

设计约定：提示与误猜引导中不得出现答案/别名/市级/黑名单词（黑名单由出题人标注易泄露专名）；末条线索必须含国家或区域锚点词保证可解；唯一例外是 Q23 的称号白名单 `late:["天下黄土第一塬"]`，仅允许出现在末条线索。扩展新题后重跑 `node tools/build.js && node test/test.js`，本报告即自动刷新。
